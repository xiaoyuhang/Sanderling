# EVE Online 行星开发自动化系统

## 🌍 项目概述

这是一个为EVE Online游戏开发的高级行星开发自动化系统，能够智能识别角色的行星开发状态，并提供一键重新采集和自动收取功能。

## ✨ 核心功能

### 🔍 状态识别功能
- **实时监控**: 自动识别所有行星的开发状态
- **提取器状态**: 检测提取器运行状态（运行中/空闲/已过期）
- **资源分析**: 分析资源密度和产量效率
- **智能预警**: 提前预警即将过期的提取器

### 🤖 自动化操作
- **一键重新采集**: 自动重启过期提取器并选择最优资源位置
- **自动收取系统**: 角色自动离站、飞行到海关办公室、收取资源、返回空间站
- **批量优化**: 同时优化多个提取器的位置和配置
- **安全保护**: 多重安全检查，确保操作安全

### 🛡️ 安全系统
- **敌对检测**: 检测敌对玩家和危险环境
- **紧急停止**: 一键停止所有自动化操作
- **安全等级检查**: 验证星系安全等级
- **飞船状态监控**: 检查飞船装备和货舱状态

## 🚀 快速开始

### 1. 启动API服务器

```bash
cd Sanderling
python pi_automation_api_server.py
```

服务器将在端口12001启动，提供以下API端点：

- `POST /api/automation/extractor/restart` - 启动提取器重启
- `POST /api/automation/collection/start` - 启动资源收取
- `GET /api/automation/task/<task_id>` - 获取任务状态
- `GET /api/automation/tasks` - 获取所有任务
- `GET /api/automation/stats` - 获取自动化统计
- `GET /api/automation/safety/check` - 安全检查
- `POST /api/automation/emergency/stop` - 紧急停止

### 2. 启动Web服务器

```bash
python -m http.server 12000
```

### 3. 访问界面

- **自动化控制台**: http://localhost:12000/pi_dashboard_automation.html
- **状态识别演示**: http://localhost:12000/pi_status_demo.html

## 🎮 使用指南

### 状态识别演示

访问 `pi_status_demo.html` 查看：

1. **实时状态监控**: 显示所有行星的当前状态
2. **提取器详情**: 每个提取器的运行状态、进度、剩余时间
3. **资源分析**: 资源类型、密度、产量统计
4. **自动化控制**: 批量操作按钮

### 自动化控制台

访问 `pi_dashboard_automation.html` 进行：

1. **一键重新采集**:
   - 选择目标资源类型
   - 设置搜索半径和密度要求
   - 配置采集周期
   - 点击"启动重新采集"

2. **自动收取资源**:
   - 输入角色名称
   - 选择目标行星
   - 设置货舱保留空间
   - 点击"启动自动收取"

3. **安全控制**:
   - 执行安全检查
   - 紧急停止所有操作
   - 查看任务日志
